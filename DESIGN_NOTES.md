## 🎨 Customization Guide

### Change Primary Color
Edit `css/styles.css` and modify the CSS variables:
```css
:root {
    --primary-color: #00d9ff;      /* Change this to your color */
    --secondary-color: #0099cc;    /* And this */
}
```

### Update Content
Edit `index.html` to:
- Add more skills in the skill cards
- Add more projects
- Update contact information
- Modify any text content

### Modify Animations
Edit `js/script.js` to:
- Adjust animation speeds
- Change intersection observer thresholds
- Customize hover effects
